What Voltix Does

Voltix monitors an AC load through the ESP32, relay, PZEM readings, LittleFS storage, Firebase sync, and this authenticated web dashboard. The ESP32 remains device-scoped; user history ownership belongs to the signed-in web account.

Electrical Formulas

Voltix displays firmware readings and keeps the math readable for quick checks.

S = V × I
P = V × I × PF

Energy and Cost

Firmware accumulates session energy while monitoring. The dashboard formats stored values without writing live data.

Energy(kWh) = Power(W) × time(hours) / 1000
Cost = kWh × tariff

Power Factor and Frequency

Power factor shows how effectively current becomes real power. Frequency helps spot unstable supply conditions when paired with voltage and current changes.

PF = realPowerW / apparentPowerVA

Overload Protection

The overload threshold is stored in device config. The warning percent creates an early warning band before the hard threshold.

warningLimit = overloadThreshold × warningPercent / 100

Offline Monitoring

If WiFi drops, firmware keeps monitoring locally. Completed sessions are saved to LittleFS first, then queued to Firebase when connectivity returns.

Pending Sync

Completed sessions are uploaded to the device queue at /devices/esp32-voltix-001/completedSessions. The web app imports them into /users/{uid}/history for the current Firebase Auth user.

Power-Loss Recovery

Firmware checkpoints active sessions in LittleFS. After restart, the ESP32 can resume when load is still present or finalize a recovered session if the load was removed. This dashboard displays recovered session badges from history metadata when available.

Firebase Contract

  • Dashboard reads /devices/esp32-voltix-001/live and /devices/esp32-voltix-001/config.
  • START and STOP write only to /devices/esp32-voltix-001/commands/current.
  • History imports completed device sessions into /users/{currentUser.uid}/history.
  • The web app never writes to /devices/esp32-voltix-001/live.
