Penjelasan Metrik

Ringkasan teknis untuk demo dan pembacaan sistem.

Power Factor

PF mendekati 1 adalah kondisi ideal. PF rendah berarti sebagian daya tidak digunakan secara efisien oleh beban.

Frequency

Standar frekuensi jaringan listrik Indonesia adalah 50Hz. Nilai yang jauh berubah bisa menandakan kondisi grid tidak stabil.

Apparent Power

Apparent power adalah daya semu dalam VA, dihitung dari voltage dikali current.

Overload Warning

Warning aktif sebelum daya mencapai overload threshold, berdasarkan warning percent pada konfigurasi.

Offline Monitoring

Voltix dapat tetap monitoring lokal tanpa internet. Data sesi disimpan lebih dulu ke LittleFS.

Pending Sync

Sesi offline disimpan lokal dan dikirim ke Firebase saat koneksi internet kembali tersedia.

Power-loss Recovery

Checkpoint sesi aktif dipakai untuk resume atau finalize setelah restart atau listrik terputus.

Offline Mode Flow

Alur singkat ketika Voltix masuk mode offline dan menyimpan sesi lokal.

1

Masuk offline dari auto no internet timeout, BOOT 10s, atau tombol captive portal "Lanjutkan Mode Offline".

2

Relay ON otomatis untuk percobaan offline pertama.

3

Jika tidak ada load sampai timeout, relay OFF dan sesi tidak masuk history.

4

BOOT 1s memulai device offline berikutnya.

5

Sesi offline yang selesai akan sync ke Firebase saat internet kembali.

State Machine

Status utama yang dipakai Voltix saat validasi dan monitoring beban.

IDLE

Relay off, menunggu perintah atau mode offline.

WAITING_LOAD / VALIDATING_LOAD

Relay on, sistem memvalidasi apakah load benar-benar terpasang.

MONITORING

Sesi aktif, energi dan biaya dihitung selama beban berjalan.

OVERLOAD

Daya melewati threshold dan sistem memutus relay untuk proteksi.

FINISHED

Sesi selesai, snapshot akhir disimpan sebelum sync.

OFFLINE

Monitoring lokal menggunakan LittleFS sampai koneksi kembali.
